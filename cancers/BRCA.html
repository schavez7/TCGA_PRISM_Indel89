Experiment notes

In this experiment, the TCGA\PRISM data was separated into three groups:

Cohort 1 Cohort 2 Cohort 3
TCGA only PRISM w/ no TCGA All samples
951 samples 356 samples 1126 samples?

Each vcf.gz file was combed and reduced to the insertions/delections (InDel) mutations. Then each was transformed into a vector via the InDel taxonomy with 89 categories. The resulting matrix for each cohort was analysed by the standard NMF algorithm w/ KL divergence "metric" provided by SigProfilerExtractor.
